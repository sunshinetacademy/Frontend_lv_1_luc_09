Flexbox — Layout الحديث

أقوى أداة في CSS لبناء Layoutات مرنة واحترافية. هنتعلم إزاي نرتب العناصر أفقياً ورأسياً بسهولة، ونبني Navigation و Cards باحتراف.

🔄
مراجعة سريعة

📚 من المحاضرة اللي فاتت

  • Display: Block, Inline, Inline-block, None
  • Position: Static, Relative, Absolute, Fixed, Sticky
  • Z-index لترتيب الطبقات
  • Overflow للتحكم في الفائض
  • Inline-block للـ Cards البسيطة

🎯 هدف النهاردة

النهاردة هنبدأ رحلة Flexbox — أقوى نظام Layout في CSS الحديث. Flexbox حل كل المشاكل اللي كانت عندنا مع Inline-block و Position. هنتعلم إزاي نرتب العناصر بسهولة في اتجاه واحد (صف أو عمود)، ونتحكم في المسافات والمحاذاة بشكل احترافي.

📦
ما هو Flexbox؟

📖 التعريف

Flexbox (Flexible Box Layout) هو نظام Layout أحادي البعد في CSS. بيخلينا نرتب العناصر في اتجاه واحد (صف أو عمود) ونتحكم في:

• اتجاه الترتيب (أفقي أو رأسي)

• المحاذاة (توسيط، توزيع، إلخ)

• المسافات بين العناصر

• حجم العناصر بشكل مرن

💡 تشبيه من الحياة

تخيل إنك في قطار:

  • Flex Container = القطار نفسه
  • Flex Items = العربات
  • flex-direction = اتجاه السكة (أفقي أو رأسي)
  • justify-content = توزيع العربات على السكة
  • align-items = مكان العربات بالنسبة للسكة (فوق، تحت، وسط)
🔴

قبل Flexbox

كنا نستخدم:

• Inline-block — فيه مشاكل المسافات

• Float — معقد ويسبب مشاكل

• Position — صعب في الـ Layout

• Tables — مش مرن

🟢

بعد Flexbox

كل حاجة بقت سهلة:

• توسيط بسطر واحد

• توزيع المسافات بسهولة

• ترتيب مرن يتكيف مع الحجم

• كود نظيف وسهل الفهم

👨‍👧‍👦
Flex Container vs Flex Items

📖 المفهوم الأساسي

Flexbox بيعتمد على علاقة بين عنصرين:

1. Flex Container (الأب): العنصر اللي عليه display: flex

2. Flex Items (الأبناء): العناصر المباشرة جوه الـ Container

CSS — تفعيل Flexbox 
/* الأب = Flex Container */
.container {
    display: flex;
}

/* الأبناء = Flex Items (تلقائياً) */
/* مش محتاج نعملهم حاجة */

📦 أول Flex Container

display: flex

لاحظ إن العناصر اصطفّت أفقياً تلقائياً!

⚠️ قاعدة مهمة

الـ Flex properties بتشتغل بس على الأبناء المباشرين. لو عندك عنصر جوه عنصر تاني جوه الـ Container، مش هيأثر عليه.

المحاور: Main Axis & Cross Axis

📖 فهم المحاور

Flexbox بيشتغل بمحورين:

1. Main Axis (المحور الرئيسي): الاتجاه اللي العناصر بتترتب فيه

2. Cross Axis (المحور العرضي): عمودي على Main Axis

🧭 المحاور في Flexbox

← Main Axis →
↑ Cross Axis ↓

في flex-direction: row (الافتراضي): Main Axis = أفقي، Cross Axis = رأسي

💡 ليه المحاور مهمة؟

• justify-content بيشتغل على Main Axis

3. أسهل: سطر واحد بس بدل ما تحسب margins.

📊
flex-grow, flex-shrink, flex-basis

📖 التحكم في حجم العناصر

ثلاث properties بتتحكم في حجم كل Flex Item:

flex-grow
النمو

إزاي العنصر بيكبر لو في مساحة فاضية. الافتراضي: 0 (مش بيكبر).

flex-shrink
الانكماش

إزاي العنصر بيصغر لو مفيش مساحة كافية. الافتراضي: 1 (بيصغر).

flex-basis
الحجم الأساسي

حجم العنصر قبل ما يبدأ ينمو أو ينكمش. بديل لـ width.

📊 flex-grow: 1 على كل العناصر

كل العناصر هتكبر بالتساوي
1
2
3

📊 flex-grow: 1, 2, 3

Item 2 هيكبر ضعف Item 1، و Item 3 ثلاثة أضعاف
1
2
3
CSS — flex properties 
/* flex-grow */
.item {
    flex-grow: 1; /* بيكبر لو في مساحة */
}

/* flex-shrink */
.item {
    flex-shrink: 0; /* مش بيصغر */
}

/* flex-basis */
.item {
    flex-basis: 200px; /* الحجم الابتدائي */
}

/* Shorthand: flex */
.item {
    flex: 1 0 200px; /* grow shrink basis */
}

💡 flex shorthand

flex: 1 = flex-grow: 1; flex-shrink: 1; flex-basis: 0%

ده بيخلي العنصر يكبر بالتساوي مع باقي العناصر اللي عندها نفس القيمة.

🔢
order — ترتيب العناصر

📖 تغيير الترتيب بدون تغيير HTML

order بيخليك تغير ترتيب العناصر بصرياً من غير ما تغير كود HTML.

📊 order: تغيير الترتيب

HTML: 1, 2, 3 — CSS: order: 2, 0, 1
1 (order: 2)
2 (order: 0)
3 (order: 1)

الترتيب الفعلي: 2 → 3 → 1

CSS — order 
.first { order: 2; }
.second { order: 0; } /* الافتراضي */
.third { order: 1; }

/* الأرقام السالبة مسموحة */
.important { order: -1; /* يروح الأول */ }

⚠️ تحذير

متستخدمش order عشان تخفي محتوى مهم. القراءات الصوتية (Accessibility) بتقرأ الترتيب من HTML، مش من CSS.

📋
ملخص Flexbox Properties

📊 Container Properties

Property الوظيفة القيم
display تفعيل Flexbox flex, inline-flex
flex-direction اتجاه الترتيب row, row-reverse, column, column-reverse
justify-content محاذاة على Main Axis flex-start, flex-end, center, space-between, space-around, space-evenly
align-items محاذاة على Cross Axis stretch, flex-start, flex-end, center, baseline
flex-wrap التفاف العناصر nowrap, wrap, wrap-reverse
gap المسافة بين العناصر أي قيمة (px, rem, %)

📊 Item Properties

Property الوظيفة القيم
flex-grow معامل النمو رقم (0, 1, 2, ...)
flex-shrink معامل الانكماش رقم (0, 1, 2, ...)
flex-basis الحجم الأساسي auto, px, %, rem
flex Shorthand grow shrink basis
align-self محاذاة فردية auto, flex-start, flex-end, center, stretch, baseline
order ترتيب العنصر رقم (سالب أو موجب)

Debugging — اكتشف الأخطاء

🔍 نشاط: اكتشف الأخطاء في CSS ده

الكود ده فيه 5 أخطاء شائعة في Flexbox.

CSS — كود فيه أخطاء ❌ 
.container {
    display: flexbox;
    flex-direction: horizontal;
    justify-content: middle;
    align-items: middle;
    gap: 20;
}

.item {
    flex-size: 1;
}
❌ الأخطاء
1. display: flexbox ❌
2. flex-direction: horizontal ❌
3. justify-content: middle ❌
4. align-items: middle ❌
5. gap: 20 (بدون وحدة) ❌
6. flex-size مش موجود ❌
✅ الكود الصحيح
.container {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  gap: 20px;
}
.item {
  flex-grow: 1;

📌 ملخص المحاضرة

  • Flexbox = نظام Layout أحادي البعد (صف أو عمود)
  • display: flex يحوّل العنصر لـ Flex Container
  • الأبناء المباشرين بيبقوا Flex Items تلقائياً
  • محورين: Main Axis (الاتجاه) و Cross Axis (عمودي عليه)
  • flex-direction: row (افتراضي), column, row-reverse, column-reverse
  • justify-content: محاذاة على Main Axis (flex-start, center, space-between, space-around, space-evenly)
  • align-items: محاذاة على Cross Axis (stretch, flex-start, flex-end, center, baseline)
  • align-self: محاذاة فردية لعنصر واحد
  • flex-wrap: wrap يسمح للعناصر بالنزول لسطور جديدة
  • gap: مسافة بين العناصر (أفضل من margin)
  • flex-grow: معامل النمو، flex-shrink: معامل الانكماش، flex-basis: الحجم الأساسي
  • flex: shorthand لـ grow shrink basis
  • order: تغيير ترتيب العناصر بصرياً
  • التوسيط الكامل: display: flex + justify-content: center + align-items: center
